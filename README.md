# Darwisy Ahmad Alfayyadl | CV / Resume

A personal online resume and portfolio website for Darwisy Ahmad Alfayyadl, built with plain HTML and CSS. This project presents a clean two-column CV layout with profile information, education, work and volunteer experience, skills, and social links.

## Project Overview

This website is designed as a lightweight and professional resume page for showcasing:

- Personal information and contact links
- Educational background
- Experience and projects
- Technical skills and languages
- Interests and profile summary

## Live Preview

Open the file directly in a browser or serve it locally with a small web server.

## How to Run

### Option 1: Open directly

- Open `index.html` in your browser.

### Option 2: Run a local server

From the project folder, run:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customization

To update the content:

1. Edit the text in `index.html`.
2. Update colors, spacing, and layout in `style.css`.
3. Replace the profile image in `assets/` if needed.
